# Hi, I'm Talha Meraj 👋

**PhD researcher in generative AI for medical imaging** at [Atlantic Technological University](https://www.atu.ie/), Ireland · Visiting student, Overton Lab, [Queen's University Belfast](https://www.qub.ac.uk/)
